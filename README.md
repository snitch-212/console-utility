# depgraph

Инструмент визуализации графа зависимостей пакетов Ubuntu (apt).
Практическая работа № 2 по дисциплине «Конфигурационное управление»,
вариант 25.

Ограничение задания: менеджеры пакетов (`apt`, `dpkg` и т. п.) и сторонние
библиотеки для получения зависимостей не используются. Проект написан на
Python 3.9+ и использует только стандартную библиотеку.

## 1. Общее описание

Программа принимает параметры анализа из командной строки. Работа разбита на
этапы; статус реализации:

| Этап | Содержание                          | Статус        |
|------|-------------------------------------|---------------|
| 1    | Прототип CLI с настраиваемыми опциями | готово        |
| 2    | Сбор данных (прямые зависимости apt)  | не реализован |
| 3    | Граф зависимостей, BFS, тестовый режим | не реализован |
| 4    | Обратные зависимости                  | не реализован |
| 5    | Визуализация (Graphviz)               | не реализован |

На этапе 1 программа проверяет все параметры и выводит их в формате
«ключ: значение».

## 2. Описание функций и настроек

### Параметры командной строки

| Опция                    | Описание                                    | По умолчанию |
|--------------------------|---------------------------------------------|--------------|
| `-p`, `--package`        | имя анализируемого пакета                   | обязательна  |
| `-r`, `--repo`           | URL репозитория (remote) или путь к файлу тестового репозитория (test) | обязательна |
| `-m`, `--repo-mode`      | режим работы с репозиторием: `remote` или `test` | `remote` |
| `-V`, `--package-version`| версия пакета                               | обязательна в `remote`, необязательна в `test` |
| `-d`, `--max-depth`      | максимальная глубина анализа зависимостей   | `1`          |

### Правила проверки параметров

- **package**: в режиме `remote` — имя пакета Debian (от 2 символов, строчные
  латинские буквы, цифры, знаки `+ - .`, первый символ — буква или цифра);
  в режиме `test` — только большие латинские буквы (`A`, `B`, …).
- **repo**: в режиме `remote` — URL со схемой `http`, `https` или `file`;
  в режиме `test` — путь к существующему читаемому файлу.
- **repo-mode**: `remote` или `test`.
- **package-version**: синтаксис версии Debian `[эпоха:]версия[-ревизия]`,
  например `5.1-6ubuntu1` или `1:2.5-1`; версия начинается с цифры.
- **max-depth**: целое число не меньше 1.

### Обработка ошибок

Любая ошибка параметров (в том числе неизвестная опция или опция без
значения) печатается в `stderr` в виде `Ошибка: <описание>`, программа
завершается с кодом `1`. При успехе код возврата `0`.

### Структура проекта

```
src/depgraph/
    __main__.py   запуск: python3 -m depgraph
    cli.py        точка входа, вывод параметров, коды возврата
    config.py     разбор и проверка параметров (класс Config)
    errors.py     исключения приложения
tests/            модульные тесты (unittest)
Makefile          цели run и test
run.sh            скрипт запуска
```

## 3. Сборка и запуск тестов

Сборка не требуется, нужен только Python 3.9 или новее.

Запуск тестов:

```
make test
```

или без make:

```
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Запуск программы:

```
./run.sh --help
make run ARGS="--help"
```

## 4. Примеры использования

Успешный запуск (на этапе 1 выводятся параметры):

```
$ ./run.sh -p bash -V 5.1-6ubuntu1 -d 3 \
    -r http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz
package: bash
repo: http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz
repo-mode: remote
package-version: 5.1-6ubuntu1
max-depth: 3
```

Режим тестового репозитория:

```
$ echo "A: B" > graph.txt
$ ./run.sh -m test -p A -r graph.txt -d 2
package: A
repo: graph.txt
repo-mode: test
package-version: (не задана)
max-depth: 2
```

Формат файла тестового репозитория будет определён на этапе 3; на этапе 1
проверяется только существование и читаемость файла.

Примеры ошибок (код возврата `1`):

```
$ ./run.sh -r http://example.org/Packages.gz -V 1.0
Ошибка: не задано имя пакета (--package)

$ ./run.sh -p Bash_X -r http://example.org/Packages.gz -V 1.0
Ошибка: недопустимое имя пакета 'Bash_X': имя apt-пакета: от 2 символов, строчные латинские буквы, цифры и знаки + - .

$ ./run.sh -p bash -r ftp://host/x -V 1.0
Ошибка: неподдерживаемая схема URL 'ftp', допустимо: http, https, file

$ ./run.sh -p bash -r http://example.org/Packages.gz
Ошибка: не задана версия пакета (--package-version)

$ ./run.sh -p bash -r http://example.org/Packages.gz -V 1.0 -d abc
Ошибка: глубина анализа (--max-depth) должна быть целым числом: 'abc'

$ ./run.sh -p bash -r http://example.org/Packages.gz -V 1.0 -d 0
Ошибка: глубина анализа (--max-depth) должна быть не меньше 1, получено 0

$ ./run.sh -p bash -r http://example.org/Packages.gz -V 1.0 -m local
Ошибка: неизвестный режим 'local' (--repo-mode), допустимо: remote, test

$ ./run.sh -m test -p A -r /no/such.txt
Ошибка: файл тестового репозитория не найден: /no/such.txt
```
